技术 FPGA 2026-09-15

  • 目标器件：xc7a35t（MicroPhase A7-Lite 开发板）

2.2 时序约束入门

时序约束是 FPGA 设计中最关键也最容易踩坑的环节。一个没有正确约束的设计，即使功能仿真通过，在实际硬件上也可能出现亚稳态或时序违例。

基本概念

建立时间（Setup Time）：时钟边沿到来之前，数据必须稳定的最小时间。保持时间（Hold Time）：时钟边沿之后，数据必须继续保持的最小时间。

# 创建主时钟约束
create_clock -period 10.000 -name sys_clk [get_ports clk_in]

# 输入延迟约束
set_input_delay -clock sys_clk -max 3.0 [get_ports data_in*]
set_input_delay -clock sys_clk -min 1.0 [get_ports data_in*]

# 输出延迟约束
set_output_delay -clock sys_clk -max 2.0 [get_ports data_out*]
set_output_delay -clock sys_clk -min 0.5 [get_ports data_out*]

常见时序违例排查

当 Timing Report 显示 WNS（Worst Negative Slack）为负值时，需要从以下几个方面排查：

  1. 检查约束是否完整——遗漏的 false_path 或多周期路径
  2. 查看关键路径的逻辑级数——是否可以通过流水线优化
  3. 确认布局布线的拥塞情况——高拥塞区域会导致绕线延迟增大

2.3 CDC 跨时钟域处理

在多时钟域设计中，信号从一个时钟域传递到另一个时钟域时，如果处理不当，会导致亚稳态问题。CDC（Clock Domain Crossing）是 FPGA 设计中必须认真对待的问题。

单比特信号：两级同步器

对于单比特控制信号，最常用的方法是两级触发器同步：

// 两级同步器 - 单比特 CDC
always @(posedge clk_b or negedge rst_n) begin
    if (!rst_n) begin
        sync_ff1 <= 1'b0;
        sync_ff2 <= 1'b0;
    end else begin
        sync_ff1 <= signal_from_domain_a;  // 第一级
        sync_ff2 <= sync_ff1;              // 第二级
    end
end

多比特信号：异步 FIFO 或握手协议

多比特数据跨时钟域不能简单用同步器，需要使用异步 FIFO（基于格雷码指针）或握手协议。Xilinx 的 FIFO Generator IP 核提供了成熟的异步 FIFO 实现。

2.4 AXI 接口基础

AXI4 是 ARM AMBA 总线家族中最常用的高性能接口协议。理解 AXI 对于使用 Zynq 或 MicroBlaze 软核的 SoC 设计至关重要。

五个通道

  • 写地址通道 (AW)：主机发送写事务地址
  • 写数据通道 (W)：主机发送写数据
  • 写响应通道 (B)：从机返回写响应
  • 读地址通道 (AR)：主机发送读事务地址
  • 读数据通道 (R)：从机返回读数据

握手协议

AXI 使用 VALID/READY 握手协议：源端驱动 VALID 信号表示数据有效，目标端驱动 READY 信号表示可以接收。只有当 VALID 和 READY 同时为高时，一次传输才会发生。

2.5 ILA 在线调试

ILA（Integrated Logic Analyzer）是 Xilinx FPGA 内嵌的逻辑分析工具，可以在不外接示波器的情况下观察内部信号波形。

基本使用流程

  1. 在 RTL 代码中设置调试标记，或在 Vivado 的 Netlist 中标记需要观察的信号
  2. 插入 ILA IP 核，配置采样深度和探针宽度
  3. 重新综合和实现设计
  4. 下载比特流后，在 Hardware Manager 中捕获波形

调试技巧

合理使用触发条件可以大幅提高调试效率。ILA 支持复合触发条件，比如"当 AXI 写通道出现特定地址且数据不为零时触发"。对于高速信号，可以使用采样率倍增模式（Sample of Data）来捕获更窄的脉冲。

RF 基础笔记

技术 RF 2026-09-20

3.1 阻抗匹配基础

阻抗匹配是射频电路设计的核心问题之一。当源阻抗与负载阻抗不匹配时，会产生信号反射，导致功率传输效率下降和信号失真。

史密斯圆图

史密斯圆图（Smith Chart）是射频工程师最常用的图形工具。它将复数阻抗平面映射到反射系数平面上，使得阻抗匹配网络的设计变得直观。

基本规则：在史密斯圆图上，串联电感使阻抗沿等电阻圆顺时针移动，串联电容逆时针移动；并联电感沿等电导圆逆时针移动，并联电容顺时针移动。

L 型匹配网络

最简单的匹配网络是 L 型网络，由两个电抗元件组成。设计步骤：

  1. 确定源阻抗 Zs 和负载阻抗 ZL
  2. 计算品质因数 Q = sqrt(R_high/R_low - 1)
  3. 根据 Q 值计算两个电抗元件的值
  4. 选择适当的拓扑（低通或高通）

3.2 滤波器设计

射频滤波器用于选择所需频段信号、抑制干扰。常见类型包括低通、高通、带通和带阻滤波器。

集总参数 vs 分布参数

在低频段（通常 < 1 GHz），可以使用集总参数（电感、电容）实现滤波器。当频率升高，元件的寄生参数会显著影响性能，此时需要使用分布参数（微带线、耦合线）实现。

切比雪夫 vs 巴特沃斯

  • 巴特沃斯：通带最平坦，但过渡带较宽
  • 切比雪夫：通带有纹波，但过渡带更陡峭
  • 椭圆函数：过渡带最陡，但有群延迟失真

3.3 S 参数分析

S 参数（散射参数）是描述射频网络特性的标准方法。与 Z 参数和 Y 参数不同，S 参数基于入射波和反射波，可以直接用矢量网络分析仪（VNA）测量。

二端口网络 S 参数

  • S11：输入反射系数（回波损耗）
  • S21：正向传输增益（插入损耗）
  • S12：反向传输增益（隔离度）
  • S22：输出反射系数

在实际测量中，需要先用校准件（开路、短路、负载、直通）进行 VNA 校准，消除测试夹具和电缆的影响，才能得到准确的 S 参数。

LabVIEW 数据采集实践

技术 LabVIEW 2026-09-25

4.1 DAQ 系统概述

LabVIEW 的数据采集（DAQ）系统基于 NI-DAQmx 驱动，支持 NI 自家的数据采集硬件以及部分第三方设备。一个典型的 DAQ 系统包括传感器、信号调理模块、DAQ 设备和运行 LabVIEW 的主机。

系统架构

  • 传感器层：热电偶、加速度计、压力传感器等
  • 信号调理：放大、滤波、隔离、激励
  • DAQ 设备：NI USB-6363、PCIe-6363 等
  • 软件层：NI-DAQmx + LabVIEW VI

4.2 模拟输入采集

模拟输入（AI）是最常见的采集类型。NI-DAQmx 提供了高层 API 来简化采集配置。

// DAQmx 采集配置伪代码
TaskHandle taskHandle;
DAQmxCreateTask("", &taskHandle);
DAQmxCreateAIVoltageChan(taskHandle, "Dev1/ai0", "",
    DAQmx_Val_Cfg_Default, -10.0, 10.0,
    DAQmx_Val_Volts, NULL);
DAQmxCfgSampClkTiming(taskHandle, "", 10000.0,
    DAQmx_Val_Rising, DAQmx_Val_FiniteSamps, 10000);
DAQmxStartTask(taskHandle);

采样率选择

根据奈奎斯特采样定理，采样率至少应为信号最高频率分量的两倍。实际工程中，通常取 5-10 倍以获得较好的波形还原度。

4.3 触发与同步

在多设备同步采集场景中，触发和时钟同步是关键。NI 设备支持软件触发、数字触发和模拟触发多种方式。

硬件触发

硬件触发的延迟远小于软件触发。对于需要精确时间戳的应用（如振动测试），应使用硬件触发配合 RTSI 或 PXI 触发总线进行多设备同步。

4.4 信号处理 VI

LabVIEW 提供了丰富的信号处理函数库，涵盖频谱分析、滤波、窗函数、统计分析等常用功能。

常用信号处理流程

  1. 时域信号采集 → 加窗（Hanning / Hamming）
  2. FFT 变换 → 频谱显示
  3. 带通滤波 → 提取目标频段
  4. 均方根（RMS）计算 → 功率评估
